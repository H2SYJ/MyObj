# PC 端重构功能矩阵

本文档是 PC 端重构的功能基线。页面迁移必须保留表内能力；移动端组件、路由元数据和交互行为不在本次视觉重构范围内。

| ---------------- | -------------- | ----------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------- | ---------------------------- |
| `/files`         | 登录、文件权限 | 目录导航、宫格/列表、搜索排序、资源管理器式选择、上传、预览、分享、移动、删除、打包 | 上传加密、分享、预览、移动、重命名、右键菜单 | `/file/*`、`/share/create`              | 保留长按、多选底栏和无限加载 |
| `/shares`        | 登录、分享权限 | 分享列表、复制链接、修改密码、单项/批量删除                                         | 删除确认、密码编辑、部分失败                 | `/share/*`                              | 保留移动卡片布局             |

## 跨页面关键链路

- `Preview`：图片、音视频、PDF、文本、未知类型、加密文件以及对象 URL 释放。
- `ShareDialog`：创建分享、密码、有效期、复制结果与关闭后的状态复位。
- 上传：加密选择、分片任务、进度同步、恢复和过期任务处理。
- 全局搜索：PC 使用路由查询参数；移动端继续使用现有页面事件。
- 文件选择：PC 保留单击、Ctrl、Shift、框选、Ctrl+A、Esc、双击和右键菜单。

## 外部验收边界

- 当前没有带测试账号和测试数据的可登录后端实例；真实文件移动、删除、打包、批量分享/回收站、离线任务和管理员权限仍需在实际运行环境验收。
- 当前主机没有可用的 Playwright WebKit 运行时；移动 WebKit 项目保留在配置中，但本轮未执行。
- 截图基线使用确定性的 API 模拟数据，只证明 PC 壳层、响应式布局和前端状态渲染，不替代真实后端、权限和部署验证。

## 阶段验收规则

- 每个迁移页面都要覆盖加载、空数据、正常、接口失败和无权限状态。
- 新增 PC 页面必须使用 `DesktopPage` 或 `desktop-content-page` 内容边界，不再增加按旧页面名枚举的兼容选择器。
- 构建或模拟数据通过不等于视觉验收；登录后的关键页面必须在实际运行实例验证。
